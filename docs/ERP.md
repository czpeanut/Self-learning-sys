# 館方後台（ERP）與家長通知

`/admin`：館方人員用 Google 登入。需要先完成雲端帳號設定（`docs/AUTH.md`，Supabase），並在 SQL Editor 重新執行一次 `supabase/schema.sql`（可重複執行，會補上 ERP 的資料表）。

## 身分與權限

| 身分 | 怎麼設定 | 總覽 | 學生與家長 | 程度檢測 | 收費帳務 | 家長通知 |
|---|---|---|---|---|---|---|
| 管理員 | `NEXT_PUBLIC_ADMIN_EMAILS`，或 `staff` 表 `role='admin'` | ✅ | ✅（含建帳號、重設密碼、停用、刪除） | ✅ | ✅ | ✅ |
| 後台老師 | `staff` 表 `role='teacher'` | ✅ | ✅（看資料、改姓名年級、管家長聯絡人） | ✅ | — | ✅ |

新增後台老師：Supabase → Table Editor → `staff` → Insert：`email`（小寫 Google 帳號）、`role`＝`teacher`、`display_name`。
後台老師是在後台出卷、看成績的人員，**館內仍然是無人化**，學生卡住時由 AI 講解。

## 功能

### 總覽（`app/api/admin/overview`、`lib/erp-stats.ts`）
使用中的學生數（帳號總數、本月新增）、**現在在館**（姓名、座位、到館時間）、今天到館／今天有練習人數、近 7／30 天活躍人數（到館或練習）、
近 14 天到館與練習人數圖、年級分布、還沒交卷的檢測、通知管道狀態。

### 學生與家長（`app/api/admin/students`、`app/api/admin/guardians`）
- 建立／批次建立學生帳號、重設密碼、停用、刪除（同 `docs/AUTH.md`）；姓名、年級、學校、備註。
- 家長聯絡人（一位學生可以有多位）：姓名、關係、Email、電話；**LINE 綁定碼**（6 位數，綁定後自動失效，可重新產生）；
  通知開關「到館／離館」「成績與繳費」；「傳測試通知」確認家長收得到。
- 每位學生的「成績單」連結。

### 程度檢測（`app/api/admin/tests`、`app/api/tests`、`lib/placement.ts`、學生端 `/tests`）
1. **出卷**：選冊別、單元、題數（5–50）、作答時間。題目來自 OLE-QS 段考真題題目池（目前數學）：
   先把題數分給單元（每單元至少 1 題，其餘依單元在真實段考出現的權重平方根分配，常考單元多一些但不會吃掉全部），
   單元內再依「這個題型在真實段考每份卷平均出幾題」分配（每題型最多 3 題）；難度約 基礎 3：標準 4：進階 3，由易到難排列。
   題目與答案存成快照（`tests.questions`），同一份檢測每位學生的題目都一樣，才能比較。
2. **派發**：勾選學生（可依年級篩選）、設期限。學生首頁會出現「有 N 份程度檢測還沒做」。
3. **作答**：限時、整份顯示、中途不給提示與對錯；**答案只在伺服器**，交卷前前端拿不到；時間到自動交卷；作答草稿存在裝置上，重新整理不會不見。
4. **批改**（伺服器）：依難度加權（基礎 1、標準 1.5、進階 2）算 0–100 分，等級 A 精熟（≥85）、B 良好（70–84）、C 基礎（55–69）、D 待加強；
   分單元、分題型答對率，列出穩固與需要加強的題型；同一份檢測的**百分等級**。
5. 學生交卷後看得到成績、各單元程度、錯題（可請 AI 講解）；錯題自動收進錯題本，作答也算進段考準備度與弱項特訓。
   家長收到成績通知。
6. 後台：各單元平均答對率、每位學生成績／等級／百分等級／需要加強的題型、匯出 CSV、讓學生重考。

### 學習程度成績單（`/admin/report-card?student=…`、`app/api/admin/report-card`）
可選統計區間、列印／存 PDF：程度檢測成績（含同卷百分等級、各單元程度）、區間內練習題數與正確率、各章掌握度與待加強的知識點、到館天數與時數。

### 收費帳務（只有管理員；`app/api/admin/billing`、`lib/billing.ts`）
- **收費方案**：每月或一次性（例：月費不限時 3,000、入會費 500）；停用方案不影響已開的帳單。
- **開月費單**：一鍵替所有「使用中、有月費方案、這個月還沒開過」的學生開單（重複按不會重開），繳費期限預設當月 10 日。
- **單筆收費**：講義費、入會費等。
- **收款**：可分次收、記收款方式（現金、轉帳、刷卡、LINE Pay、其他）與經手人；收滿自動改為已繳；收款可刪除（帳單改回未繳）。
- 折扣、作廢、**繳費通知**（傳給家長的 LINE／Email）。
- **其他收支**：房租、水電、人事、耗材…
- **月報表**：當月應收、實收（依收款方式）、目前未收總額、逾期名單（逾期天數）、其他收入、支出、淨額。
- **匯出 CSV**（帳單、收款、收支；Excel 直接開，不會亂碼）。

金額都是新台幣整數。這是館內的收費管理，**不是統一發票**；需要開立電子發票時要另外串接加值中心。

## 家長通知

孩子**到館**、**離館**（含在館時間、專注時間、練習題數與正確率、孩子的心得）、**程度檢測成績**、**繳費通知**，
依家長的通知開關傳到 LINE 和／或 Email。每則通知都有紀錄（後台「家長通知」：成功／失敗／略過）。

學生簽到／簽退在 K書模式（`/study`），由 `/api/attendance` 寫到館紀錄並通知家長（`lib/notify.ts`）。

### LINE 官方帳號（建議）

> LINE Notify 已於 2025-03-31 停止服務，這裡用的是 LINE 官方帳號的 Messaging API。

1. 到 LINE Official Account Manager 建立官方帳號（免費方案每月有一定的免費訊息則數，超過要升級方案）。
2. 在 LINE Developers 對這個官方帳號啟用 **Messaging API**，記下：
   - **Channel secret**（Basic settings）→ 環境變數 `LINE_CHANNEL_SECRET`
   - **Channel access token (long-lived)**（Messaging API）→ `LINE_CHANNEL_ACCESS_TOKEN`
3. Messaging API → **Webhook URL** 填 `https://<你的網址>/api/line/webhook`，開啟「Use webhook」，按 Verify。
   官方帳號的自動回應訊息建議關閉（避免和系統回覆重複）。
4. 後台「學生與家長」新增家長 → 系統產生 6 位數綁定碼 → 給家長官方帳號的 QR code 與綁定碼。
5. 家長加好友、傳綁定碼 → 系統回覆「綁定完成」，之後就會收到通知。家長封鎖官方帳號會自動解除綁定。
   一位家長有多個孩子時，用每個孩子各自的綁定碼各綁一次即可。

### Email（Resend）

1. 到 https://resend.com 註冊，驗證寄件網域（例：`your-domain.tw`）。
2. 建立 API key → `RESEND_API_KEY`；寄件人 `MAIL_FROM`，例：`自習館 <notify@your-domain.tw>`。
3. 後台家長聯絡人填 Email 即可（Email 不需要綁定）。

兩個管道都設定時，同時有 LINE 綁定與 Email 的家長兩邊都會收到。沒設定的管道會記為「略過」。
金鑰只放 Vercel 環境變數或 `.env.local`，不要貼在對話裡、不要 commit。

## 資料表（`supabase/schema.sql`）

`plans`、`guardians`、`attendance`、`tests`、`test_assignments`、`invoices`、`payments`、`ledger`、`notifications`；
`students` 增加 `plan_id`、`school`、`note`；`staff.role` 增加 `teacher`。
全部開啟 RLS 且沒有前端政策：只能透過 `/api/admin/*`、`/api/tests`、`/api/attendance`（伺服器、service role）讀寫，每次都驗證身分與角色。

## 之後可以做
- 沒到館提醒（例：平日 19:00 還沒到館，通知家長）——需要排程（Vercel Cron）。
- 家長自己的帳號：在手機上看孩子的日報、成績單、繳費紀錄。
- 線上繳費（LINE Pay、信用卡）與電子發票。
- 檢測的試題分析（每題答對率、鑑別度），題目有誤時回報 OLE-QS 題號。
