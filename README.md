# 自習練功房（Self-learning-sys）

國中生自主學習系統雛形，設計給**無人化智慧 K書中心**使用（館內沒有輔導老師）：到館簽到、番茄鐘專注、自適應練習、**問 AI**（沿用 student-app 的 Gemini 解題與幾何輔助圖模組）、家長日報。

學生自己選練習範圍，系統出一波題目，**依錯題狀況產生下一波**，結束後產出**學習狀況評估報告**。

知識點目錄沿用 [student-app](https://github.com/czpeanut/student-app) 的 `lib/taxonomy.ts`（9 科：科目 → 大單元 → 知識點）。

完整規劃（功能清單、引擎設計、第二階段）見 **[docs/PLAN.md](docs/PLAN.md)**。

**段考衝刺**（`/exam`）：選段考範圍（沒選就依日期推算、帶主流範圍）→ 列出所有題型 → 量化還缺什麼 → 用 OLE-QS 真實段考題練習，見 **[docs/EXAM.md](docs/EXAM.md)**。

**弱項特訓**（`/drill`）：挑出錯題和弱項題型重複練習——每波先重做一題錯題本原題、再出同題型新題，一開始降一級難度，同一題型連續答對 3 題才算達標；練很多題還是常錯就停下來改看 AI 講解。

**今日成果報告**（`/today`）：每天練習的彙整——題數與每日目標、和昨天／近 7 天的自己比、各題型掌握度變化、錯題本新增／重做／克服、特訓達標、段考準備度變化，以及明天的具體下一步（可直接點開）。

**雲端帳號**（選用）：設定 Supabase 後，學生用館方發的帳號密碼登入、紀錄存雲端（換裝置也看得到），館方管理員用 Google 登入 `/admin` 建立與管理學生帳號；沒設定就用裝置帳號，見 **[docs/AUTH.md](docs/AUTH.md)**。

**館方後台 ERP**（`/admin`，需雲端帳號）：使用中學生數與在館人數、派發程度檢測（OLE-QS 段考真題、伺服器批改、等級與百分等級）、學習程度成績單（可列印）、收費方案／開月費單／收款／其他收支／月報表／CSV；家長透過 **LINE 官方帳號或 Email** 收到到館、離館、檢測成績、繳費通知，見 **[docs/ERP.md](docs/ERP.md)**。

**學習習慣**（`/habits`）：依錯題量、作答速度、錯的題型（加上把握度、求助方式、練習分布）判斷作答模式（衝動型、觀念缺口、投入不足、高估自己…），給出有教育心理學研究依據的改善建議，偵測到衝動型作答時自動開啟「冷靜作答」，家長日報也會顯示，見 **[docs/LEARNING-PROFILE.md](docs/LEARNING-PROFILE.md)**。

## 快速開始

```bash
npm install
cp .env.example .env.local   # 填 GEMINI_API_KEY：AI 出題、AI 詳解（問 AI）都需要
npm run dev                  # http://localhost:3000
```

**不設 API Key 也能完整體驗**：27 個數學計算型知識點（整數運算、方程式、畢氏定理、乘法公式、數列、機率、統計…）
由程式出題，答案保證正確；其他知識點會出清楚標示的「示範題」，只用來體驗流程。

## 指令

| 指令 | 說明 |
|---|---|
| `npm run dev` | 開發伺服器 |
| `npm run build` | 正式建置（含 ESLint＋型別檢查） |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | 引擎、出題器、家長日報、段考推算與準備度的自我檢測 |
| `npm run bank` | 從 OLE-QS 匯出檔重建題目池與段考統計（`npm run build` 會自動執行） |

## 部署（Vercel）

匯入此 repo 後設定環境變數 `GEMINI_API_KEY`（及可選的 `GEMINI_MODEL`）；建議設 `SITE_ACCESS_CODE`（整站通行碼，擋館外的人、保護 AI 額度）。題目池會在建置時從 OLE-QS 匯出檔自動產生。雛形沒有資料庫，資料存在學生瀏覽器。

## 安裝成 App

已是 PWA：部署後在手機／平板點「📲 安裝 App」即可加到主畫面（iPhone 會顯示圖解）。上架商店與館內平板鎖定見 [docs/APP.md](docs/APP.md)。
